# Player Indicators Plus

Player Indicators Plus gives you more control over how nearby players are
highlighted. Names and colors can change when another player enters or leaves a
Wilderness or PvP area, even if you stay in a safe area.

## Features

- Separate colors for your player, friends, friends chat, team members, clan
  members, and everyone else.
- Different friend and player colors inside combat zones.
- Optional names above players, colored tiles, minimap labels, and right-click
  menu colors.
- Friends chat and clan rank icons.
- RuneLite color pickers for every category.

The plugin only changes how players are displayed. It does not change clicks,
combat options, or game input.
