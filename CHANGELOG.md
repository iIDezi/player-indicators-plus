# Changelog

## 1.4.0

- Added the party member highlighting from the latest combined release to the standalone plugin.
- Added Highlight party members, enabled by default, and a Party member color picker with default #EA7B5B.
- Uses the current RuneLite/Party Hub membership for names, tiles, minimap labels, and player menu colors.
- Updates when members join, leave, or log out, and restores category colors when party highlighting is disabled.
- Gives party colors priority over friend, clan, team, and combat-zone colors while preserving own-player settings.
- Retained the standalone configuration group and all existing setting keys so installed users keep their saved settings.

## 1.3.0

- Split Player Indicators Plus into its own RuneLite project and development client.
- Kept independent per-player Wilderness and PvP-area detection.
- Kept Friends - Combat Zones, Others - Combat Zones, and Others - Safe Areas controls.
- Preserved native RuneLite color pickers and the collapsible Highlight options section.
- Removed all Spotify Controller code, settings, UI, networking, and launch behavior.
- Removed the unused Lombok build dependency.
